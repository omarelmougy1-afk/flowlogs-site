Team-Stundenzettel

Fehlende Buchungen fallen sofort auf

Jede Person, jeder Tag, eingefärbt im Verhältnis zu einem Arbeitstag. Ein Tag ohne Buchung bekommt einen roten Rahmen, damit Sie vor dem Sprint-Review wissen, wen Sie erinnern müssen. Klicken Sie auf einen Tag, um die zugehörigen Zeiterfassungen zu sehen.

  • Farben für weniger als einen halben Tag, einen Teil des Tages, einen vollen Tag und mehr als einen vollen Tag
  • Ein Klick auf einen Tag führt direkt zu seinen Zeiterfassungen

Flow-Bericht

Kapazität und Schätzungen in einer Ansicht

Gesamtzeit, Kapazität und Flow-Effizienz oben, darunter eine kurze Liste Needs attention, und jede Zahl lässt sich von der Person über das Projekt bis zum Vorgang nachverfolgen.

  • Vorgänge über ihrer ursprünglichen Schätzung stehen unter Needs attention
  • Die Flow-Effizienz setzt die aufgewendete Zeit ins Verhältnis zur Kapazität

Datenschutz und Architektur

Ihre Jira-Daten bleiben in Jira

Flowlogs läuft auf Atlassian Forge und sendet nichts an Server außerhalb von Atlassian.

Liest Jira mit Ihren Rechten

Jede Person sieht nur die Projekte, Vorgänge und Zeiterfassungen, die ihre Jira-Berechtigungen ohnehin erlauben.

Atlassian-Forge-Speicher

Einstellungen und gespeicherte Ansichten liegen im Atlassian-Forge-Speicher und nirgendwo sonst.

Keine externen Server

Keine eigenen Server, keine Analysetools und keine Tracking-Skripte.

Exporte im Browser

PDF-, Excel- und CSV-Dateien werden in Ihrem Browser erstellt und auf Ihrem Gerät gespeichert.

Häufige Fragen

Alles, was Sie wissen müssen

Ist Flowlogs kostenlos?

Ja. Flowlogs ist im Atlassian Marketplace kostenlos, ohne Nutzerlimit.

Verlassen Daten Jira?

Nein. Flowlogs läuft vollständig auf Atlassian Forge: Der Code läuft in der Cloud von Atlassian, die Einstellungen bleiben im Forge-Speicher, und Exporte entstehen in Ihrem Browser.

Auf welchen Tag zählt eine Zeiterfassung?

Auf den Tag, an dem sie in Jira erfasst wurde. Ein Bericht über die letzte Woche zeigt also genau, was letzte Woche eingetragen wurde. Die Kapazität richtet sich nach den Stunden pro Tag und Tagen pro Woche, die Sie festlegen.

Wer sieht was?

Flowlogs liest Jira im Namen der Person, die es nutzt. Jede Person sieht also nur die Zeiterfassungen und Vorgänge, die Jira ihr ohnehin zeigt.

Wird Arabisch unterstützt?

Arabische Namen und Texte erscheinen korrekt auf dem Bildschirm und in jedem Export, auch im PDF. Die App selbst ist auf Englisch; diese Website gibt es auch auf Arabisch, Spanisch, Französisch und Deutsch.

Wissen, wohin die Zeit Ihres Teams gegangen ist, auf einer einzigen Jira-Seite.

Ihr Team muss nichts Neues lernen. Flowlogs liest die Zeiterfassungen, die es bereits in Jira führt.
